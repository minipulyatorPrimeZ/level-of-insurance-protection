# D. PRO: Клиент под защитой — решение

## Запуск (воспроизводит результат целиком)
    pip install -r requirements.txt
    python train.py   --data_dir . --seed 679035307                   # -> models/a_00..29.txt, b_00..29.txt, meta.json  (~70 c, CPU)
    python predict.py --test hard_test_closed.csv                     # -> submission_seed_679035307.csv   (итоговая смесь)
    python predict.py --test hard_test_closed.csv --members a         # -> submission_seed_679035307_A.csv (только ансамбль A, для сравнения)
Обучение использует только `hard_train.csv`. Сиды моделей = SEED + i, `deterministic=True`. Проверено: повторный запуск из чистой
папки (в том числе с OMP_NUM_THREADS=1) даёт побайтово идентичные веса и submission. Контрольные суммы файлов для закрытого теста
(Python 3.13, lightgbm 4.7.0, numpy 2.5.3, pandas 3.0.5):

    796d33f864a0d843f09075251d79451cb6c1b271bd287298712085ea94cbc400  closed/submission_seed_679035307.csv     (смесь)
    42e7921ac9ff50692209b676c23d67eee3b770920f63fcf4ee52d7af05be339e  closed/submission_seed_679035307_A.csv   (только A)

(на другой платформе или версии lightgbm возможны отличия в последних знаках; на качество это не влияет). Для другого seed: `python train.py --seed <любой>`.

## Модель
Взвешенное среднее двух ансамблей LightGBM-регрессоров, цель в исходной шкале (0..100), итог клипуется в [0, 100]:
* **A, вес 2/3:** все признаки в каждом дереве (`colsample_bytree=1.0`), `subsample=0.8`, `min_child_samples=20`;
* **B, вес 1/3:** `colsample_bytree=0.6`, `subsample=0.7`, `min_child_samples=40`;
* общее: 700 деревьев, `learning_rate=0.02`, 15 листьев, `reg_lambda=10`; в каждом ансамбле 30 моделей с разными сидами, простое среднее.

Предобработка: категории → целые коды; для house_value / car_value / average_claim_cost NaN → 0 плюс бинарный флаг «нет объекта»;
остальные пропуски обрабатывает LightGBM.

Почему так. Метки train сильно зашумлены (любая модель имеет CV-RMSE ≈ 10), метки открытого теста — заметно чище (RMSE лучших
решений ≈ 1.2). Поэтому абсолютный CV на train не различает модели, различать приходится по парным разностям ошибок и по открытому тесту.
Лучше всего работает гладкая, умеренно гибкая модель с усреднением по многим сидам: усреднение убирает случайность обучения одной
модели (одна модель отклоняется от среднего по 30 сидам на ≈ 0.7 RMS). Смесь двух конфигураций страхует от неоднозначности по
`colsample`: train-CV предпочитает 0.6, открытый тест — 1.0 (подробности ниже).

## Как выбирались гиперпараметры (честная оговорка)
Часть выборов (пп. 5–13) делалась по оценкам открытого теста на платформе; закрытый тест для настройки не использовался.
Независимая проверка на одном train (`experiments/exp_cv_hyperparams.py`, повторная 5-fold CV, парные разности ошибок
с ансамблем A; «+» = вариант хуже A):

| вариант | ΔMSE на train-CV (± SE) | согласие с открытым тестом |
|---|---|---|
| 31 лист / 63 листа | +1.1 (±0.27) / +2.5 (±0.42) | да, хуже |
| 1400 деревьев | +1.1 (±0.16) | да, хуже |
| 350 деревьев | +0.9 (±0.23) | не проверялось на тесте |
| λ = 30 | +0.37 (±0.17) | да, хуже |
| 7 листьев, min_child 40 / 80, λ = 3 | |Δ| ≤ 0.3, в пределах шума | min_child 20 на тесте чуть лучше 40 (84.77 против 84.59) |
| colsample 0.6 / 0.4 | −1.0 (±0.23) / −0.7 (±0.33), т. е. лучше A | **нет**: на открытом тесте colsample 1.0 лучше (84.0 против 82.5) |
| ансамбль B целиком | −0.78 (±0.24), лучше A | **нет**: на открытом тесте B хуже A (83.65 против 84.77) |

Число листьев, число деревьев и λ подтверждаются независимо. Выбор colsample расходится: train-CV предпочитает 0.6, открытый тест — 1.0.
Возможное объяснение: train-CV измеряет близость к зашумлённым меткам, а тест — к более чистым, и оптимальная гладкость у этих двух
задач различается. Это допущение, оно не проверялось.

**Смесь A + B как ответ на это расхождение.** Оба источника согласны, что смесь полезна:
* train-CV: смесь «2/3 A + 1/3 B» против контроля «2/3 A + 1/3 A′» (та же A с другим сидом, т. е. тоже усреднение двух моделей)
  даёт ΔMSE = −0.47 ± 0.08, то есть B добавляет разнообразие, а не просто второй сид;
* открытый тест: по баллам A (84.77), B (83.65) и расстоянию между их предсказаниями (RMS 0.73) точное тождество
  `MSE(w) = (1−w)·MSE_A + w·MSE_B − w(1−w)·‖p_A − p_B‖²/n` даёт для w = 1/3 балл 85.17 (кривая плоская: 0.25 → 85.15, 0.5 → 85.08).
  Смесь на платформе открытого теста не отправлялась, это расчётная оценка. Вес 1/3 выбран у плоского оптимума.
